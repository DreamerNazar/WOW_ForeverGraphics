# ForeverGraphics

Аддон для WoW Forever (клиент 3.3.5a), выставляющий графические CVar'ы
сверх того, что доступно в стандартном меню настроек.

## Установка
Скопировать папку `ForeverGraphics` в `World of Warcraft/Interface/AddOns/`.

## Команды
- `/fg` — справка
- `/fg apply <low|high|ultra>` — применить пресет
- `/fg reset` — вернуть значения, сохранённые до первого применения
